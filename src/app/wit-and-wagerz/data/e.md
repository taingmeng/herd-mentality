## 💻 Section 1: Code Architecture, Compiler Secrets & Languages (1–40)

**1. In what year did Bjarne Stroustrup officially release the first commercial version of C++?**

* **Answer:** 1985
* **Fun Fact:** It was built as an enhancement to the original C language, adding object-oriented classes while maintaining low-level efficiency and performance.

* **Answer:** 32 bits
* **Fun Fact:** Double-precision floats utilize 64 bits, allowing programmers to minimize rounding errors during complex decimal calculations.

**3. What is the maximum character length of a variable name allowed in the original 1957 version of Fortran?**

* **Answer:** 6 characters
* **Fun Fact:** This tight constraint forced early engineers to use highly cryptic abbreviations, which made reading legacy code a nightmare.

**4. In what year was the programming language PHP first released by Rasmus Lerdorf?**

* **Answer:** 1995
* **Fun Fact:** PHP originally stood for "Personal Home Page tools." Today, it powers a massive percentage of content-managed websites across the internet.

**5. How many primitive data types are officially built into the core Java programming language?**

* **Answer:** 8
* **Fun Fact:** They are `byte`, `short`, `int`, `long`, `float`, `double`, `boolean`, and `char`. All other data types are treated as objects.

**6. What is the standard number of spaces recommended by the official PEP 8 style guide for a single level of indentation in Python?**

* **Answer:** 4
* **Fun Fact:** While tabs or alternative space counts are syntactically legal, Python developers universally stick to 4 spaces to ensure code readability.

**7. In what year did Microsoft release the first public version of TypeScript to open-source developers?**

* **Answer:** 2012
* **Fun Fact:** Built as a strict syntactical superset of JavaScript, it added static typing to help engineering teams maintain massive web codebases.

**8. How many keywords make up the entire syntax of the original ANSI C programming language (C89)?**

* **Answer:** 32
* **Fun Fact:** Despite its incredibly tiny keyword footprint, C remains one of the most powerful and widely used languages for operating systems and embedded hardware.

* **Answer:** 1996
* **Fun Fact:** Java achieved this portability by compiling code into bytecode, which runs inside a standardized Java Virtual Machine (JVM) built for each platform.

**10. How many levels of abstract visibility (access modifiers) are available to programmers in Java?**

* **Answer:** 4
* **Fun Fact:** They are `public`, `protected`, `private`, and the default package-private modifier (which has no explicit keyword).

**11. In what year did Apple debut its modern programming language, Swift, to replace Objective-C for iOS development?**

* **Answer:** 2014
* **Fun Fact:** Swift was designed to be safer, faster, and more expressive, eliminating entire categories of common programming bugs like null pointer exceptions.

**12. How many bits make up a single basic character encoded under the classic ASCII text standard?**

* **Answer:** 7 bits
* **Fun Fact:** A 7-bit system can map exactly 128 unique values, which was plenty of space to hold the English alphabet, numbers, and basic system command codes.

**13. In what year did Netscape release JavaScript, written by developer Brendan Eich in just 10 days?**

* **Answer:** 1995
* **Fun Fact:** To capitalize on the massive hype surrounding Java at the time, Netscape rebranded the language from "LiveScript" to "JavaScript" at the last minute.

**14. How many distinct basic numeric values can be represented by a single unsigned 8-bit integer (`uint8`)?**

## 🌐 Section 2: Networking, Databases & Internet Protocols (41–80)

**41. What is the standard network port number assigned to carry unencrypted HTTP web traffic?**

* **Answer:** 80
* **Fun Fact:** Secure, encrypted HTTPS traffic automatically routes through port 443, utilizing SSL/TLS protocols to safeguard data.

**42. In what year was the Domain Name System (DNS) first invented, mapping messy numeric IP addresses to clean domain words?**

* **Answer:** 1983
* **Fun Fact:** Invented by Paul Mockapetris, the system automated directory lookup, making it so humans didn't have to carry books of IP numbers to view sites.

**43. How many bits of data make up a single modern secure IPv6 internet protocol address string?**

* **Answer:** 128 bits
* **Fun Fact:** IPv6 opens up an astronomical number of unique addresses (340 undecillion), ensuring we will never run out of web paths for smart gadgets.

**44. What is the default port number used to establish an unencrypted Telnet remote terminal network connection?**

* **Answer:** 23
* **Fun Fact:** Telnet sends data in plain text, letting eavesdroppers steal passwords. Secure developers utilize encrypted SSH connections on port 22 instead.

**45. In what year did the Internet Engineering Task Force (IETF) officially publish the standard specification for the HTTP/1.1 protocol?**

* **Answer:** 1997
* **Fun Fact:** HTTP/1.1 introduced persistent connections by default, allowing a browser to pull multiple images and assets over a single socket without closing it.

**46. How many distinct decimal octets compose a standard, fully written IPv4 network address layout (like `192.168.1.1`)?**

* **Answer:** 4
* **Fun Fact:** Each of the 4 octets represents an 8-bit number, meaning every section can scale anywhere from exactly 0 up to 255.

**47. What is the standard default network port assignment designated for secure SSH remote shell terminal traffic?**

* **Answer:** 22
* **Fun Fact:** SSH utilizes strong public-key cryptography to encrypt the entire command session, replacing legacy unencrypted tools like Telnet and Rlogin.

**48. In what year did Tim Berners-Lee officially publish the historic first ever operational website from his lab at CERN?**

* **Answer:** 1991
* **Fun Fact:** Hosted on a NeXT computer, the simple text-only page was dedicated entirely to explaining how the World Wide Web worked and how users could set up servers.

**49. How many characters make up the exact fixed maximum text length of a standard SHA-256 cryptographic hash value?**

* **Answer:** 64 characters
* **Fun Fact:** SHA-256 converts any amount of data into a fixed 64-character hexadecimal string, serving as the security baseline for file integrity and Bitcoin mining.

**50. What is the default network port assignment used by relational databases running MySQL server engines?**

* **Answer:** 3306
* **Fun Fact:** This classic port number is recognized by firewalls globally, letting applications open database pools to save and read structured data.

**51. In what year did Vint Cerf and Bob Kahn officially publish the foundational paper outlining the TCP network protocol?**

* **Answer:** 1974
* **Fun Fact:** Often crowned the "Fathers of the Internet," their design split packet assembly away from routing logic, launching the TCP/IP suite.

**52. How many layers of data abstraction compose the simplified, real-world TCP/IP internet network model stack?**

* **Answer:** 4
* **Fun Fact:** Unlike the theoretical 7-layer OSI model, the practical TCP/IP suite compresses networking down into: Network Access, Internet, Transport, and Application.

**53. What is the default network port number assigned to carry unencrypted File Transfer Protocol (FTP) command control data?**

* **Answer:** 21
* **Fun Fact:** FTP typically uses port 21 to send commands, while opening a separate dynamic port (like port 20) to stream the raw data blocks.

**54. In what year did Marc Andreessen launch the Mosaic web browser, the tool that popularized the graphics-rich internet?**

* **Answer:** 1933 (Correction: **1993**)
* **Fun Fact:** Mosaic was the first browser to display images inline directly alongside text paragraphs on a single page, completely transforming the web from a niche academic playground.

**55. How many bits are packed inside a single standard media access control hardware address (the MAC address)?**

* **Answer:** 48 bits
* **Fun Fact:** Burned directly into network cards at the factory, a 48-bit layout is traditionally written as 12 hexadecimal characters separated by colons.

**56. What is the standard port number used by network routers to exchange automated DNS directory lookup traffic?**

* **Answer:** 53
* **Fun Fact:** DNS query traffic typically runs over UDP port 53 to maximize lookup speeds, switching to TCP port 53 during heavy zone file transfers.

**57. In what year did the tech industry establish the first official specification for the lightning-fast WebSocket protocol?**

* **Answer:** 2011
* **Fun Fact:** WebSockets opened up true, full-duplex bi-directional communication channels over a single TCP connection, allowing real-time web applications and live chats to thrive.

**58. How many distinct server status code families classify outcomes under the global HTTP networking standard?**

* **Answer:** 5
* **Fun Fact:** The families are 1xx (Informational), 2xx (Success), 3xx (Redirection), 4xx (Client Error - like 404), and 5xx (Server Error - like 500).

**59. What is the default network port assignment reserved for sending outbound emails using the Simple Mail Transfer Protocol (SMTP)?**

* **Answer:** 25
* **Fun Fact:** While port 25 remains the standard for server-to-server mail relays, modern client applications typically use encrypted port 587 or 465 to send mail.

**60. In what year did the Apache Software Foundation release the initial open-source version of the Apache HTTP Server?**

* **Answer:** 1995
* **Fun Fact:** Apache quickly grew to dominate the early internet ecosystem, serving as the foundational web server that powered the dot-com boom.

**61. How many bits form the subnet mask block of a standard Class C private home network configuration (`/24`)?**

* **Answer:** 24 bits
* **Fun Fact:** A 24-bit mask maps to `255.255.255.0`, which leaves exactly 8 bits open for host devices, capping the network at 254 active IP connections.

**62. What is the default network port assignment used by web caches running the Redis database memory engine?**

* **Answer:** 6379
* **Fun Fact:** Redis stores data sets entirely inside system RAM to deliver sub-millisecond lookups, keeping this port highly active on backend infrastructures.

**63. In what year was the TLS (Transport Layer Security) 1.0 cryptographic protocol officially specified as the successor to SSL 3.0?**

* **Answer:** 1999
* **Fun Fact:** TLS repaired severe design flaws in Netscape's old Secure Sockets Layer (SSL) system, standardizing internet data encryption pipelines.

**64. How many baseline ACID transactional properties guarantee absolute data reliability inside relational database networks?**

* **Answer:** 4
* **Fun Fact:** The 4 critical guarantees are Atomicity (all or nothing), Consistency, Isolation, and Durability, protecting databases from system crashes.

* **Fun Fact:** PostgreSQL is a powerful open-source object-relational database system, utilizing this fixed port lane to handle heavy SQL queries.

**67. How many bits make up the header checksum tracking block inside a standard legacy IPv4 network packet?**

* **Answer:** 16 bits
* **Fun Fact:** The checksum verification block forces routers to calculate packet math at every hop, a process that was completely removed in modern IPv6 to maximize routing speeds.

**69. In what year did a team of computer scientists officially unleash the lightweight JSON data exchange standard formatting style?**

* **Answer:** 2001

**70. How many bytes make up the baseline minimum header size of a standard User Datagram Protocol (UDP) packet?**

* **Answer:** 8 bytes
* **Fun Fact:** UDP's tiny 8-byte header makes it incredibly lean and fast, perfect for streaming real-time video feeds and multiplayer gaming where speed beats packet tracking.

**71. What is the default network port number assigned to handle secure, encrypted IMAP (Internet Message Access Protocol) mail traffic?**

* **Answer:** 993
* **Fun Fact:** Running IMAP over an SSL/TLS layer encrypts the connection between your device and the mail server, protecting your email contents from sniffing.

**76. How many distinct bit slots form the maximum size window scaling field tracking factor inside a standard TCP header?**

* **Answer:** 16 bits

**77. What is the default network port used by developers to query a decentralized Redis cache cluster sentinel management instance?**

* **Answer:** 26379
* **Fun Fact:** Sentinel nodes continuously monitor master and slave Redis instances, executing automated failovers if a master database crashes.

**78. In what year did the internet-defining security standard HTTPS first get introduced to web browsers by Netscape Communications?**

* **Answer:** 1994
* **Fun Fact:** Developed alongside early versions of the SSL protocol, it was originally built to secure credit card transactions and launch early e-commerce.

**79. How many bytes make up the absolute baseline maximum transmission unit (MTU) packet ceiling for standard Ethernet networks?**

* **Answer:** 1500 bytes
* **Fun Fact:** If a data block is larger than 1,500 bytes, routers must chop it up into smaller fragments to pass it through standard network switches.

**80. What is the default port number assigned to collect secure, encrypted POP3 mail traffic over an SSL/TLS tunnel?**

* **Answer:** 995
* **Fun Fact:** Port 995 locks down the old email downloading pipeline, ensuring that login credentials cannot be stolen over open public networks.
